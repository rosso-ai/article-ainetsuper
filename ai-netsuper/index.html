AIでネットスーパーを使おう

はじめに

最近、我が家ではネットスーパーでの買い物をAIに任せることにしました。

理由としては、こんな感じです。

  • 買い物に行くと、昼休みの1時間のうち30分がだいたい潰れてしまう。場合によっては、もっと時間がかかる。
  • 3日に1回くらいのペースで買い物をするのがめんどくさいし、忘れる。
  • 何を買えばいいか考えるのがめんどくさいし、忘れる。

3日おきの買い物を週1回に → AIに献立も任せる

我が家は夫婦と1歳10か月の娘の3人家族です。食料品の買い物は基本的に私が担当しています。（ちなみに夫婦ともにリモートワークです）

これまでは3日に1回くらいのペースで買い物に行っていました。なぜ「3日おき」かというと、いつも買ってるカット野菜の賞味期限がだいたい3日だからです。

カット野菜のイメージ（生成AIで作成）

我が家は朝と夜に、袋入りのカット野菜（千切りキャベツなど）をサラダにして食べます。カット野菜は袋を開けて皿に盛り付けるだけでいいので調理の手間がないですし、野菜くずも出ません。とても楽です。

しかしカットされているせいか賞味期限が短く、3日に1回は買い物に行かなければならないスケジュールになっていました。スーパーまでは自転車で10分ほど。めんどくさい！

そこでライフのネットスーパーを使うことにしました。ライフのネットスーパーでは、税抜8,000円以上購入しないと送料がかかります。3日分の買い物ではこの金額に届きません。送料がかさんでしまいます。そこで、買い物を1週間分にまとめることにしました。

ただし、買い物を週1回にすると3日しかないカット野菜の賞味期限が途中で切れてしまいます。献立そのものを変える必要があります。そこで、AIに献立も考えてもらうことにしました。

AIに買い物と献立を考えてもらう

過去のレシートの分析

そもそも、我が家は普段スーパーで何をどのくらい買っているのか、正確にはわかっていませんでした。そこで、手元にたまっていたレシートのうち約1か月分を写真に撮り、AIに文字起こしと分析をしてもらいました。使ったのは Claude Code と ChatGPT です。

レシートのイメージ（生成AIで作成）

12枚の合計は約73,000円で、1週間あたり約13,000円でした。牛乳は37本（1週間に6〜7本）、食パンは18袋です。たぶんレシートが残っていない日もあるので、実際に買った量はこれより多いはずです。

商品の候補として、購入間隔で3つに分けました。

1週間の献立

次に、この買い方と普段の食事をもとに、用意も、食べるのも、選ぶのも、できるだけ楽な献立をAIに考えてもらいました。

朝はジャムを塗った食パンとサラダ、夜はご飯・みそ汁・サラダ・おかず1品です。夜のおかずは曜日ごとに替え、焼くだけ・温めるだけのもの（味付きの焼肉、チルドのハンバーグ、冷凍の唐揚げなど）にしました。

夜ごはんのイメージ（生成AIで作成）

いちばんの問題は、期限が3日のカット野菜です。考えてみると、娘の野菜は毎日、冷凍野菜を電子レンジで温めて出しています。それなら大人の野菜も冷凍野菜にすればよいのではないか、と思いました。そこで、配達の日の夜から3日分（6食）はカット野菜、残りの4日分（8食）は冷凍野菜を使う献立をAIに組んでもらいました。冷凍野菜は、夜は冷凍ブロッコリー、朝は冷凍いんげんにして、どちらにもコーンを足します（最近娘はめちゃくちゃコーンを要求してきます）。

AIでネットスーパーを操作する

ネットスーパーの操作には、AIがブラウザを操作できる Chrome の拡張機能「Claude in Chrome」を使いました。AIがライフのネットスーパーの画面を開き、献立に必要な商品が実際に買えるかを確かめながら、1週間分の買い物リストを作りました。

特に便利だったのは、商品パッケージの画像も読んで、容量や表示を確かめてくれたことです。サラダはこれまで袋から出すだけで食べていたので、冷凍野菜も電子レンジを使わずに食べられるものを探してもらいました。AIが選んだのは、パッケージに「自然解凍でOK」と書かれた商品（富士通商の「手間なし！」シリーズのブロッコリーといんげん）です。冷凍コーンには、自然解凍できるという表示が確認できなかったので、コーンは缶詰にしました。1食分の量も「ブロッコリー70g＋コーン40g」のように出してくれました。

AIに買い物を考えてもらいましたが、一部の商品はネットスーパーで取り扱われていないこともわかりました。たとえば、店頭で買っていた千切りキャベツ（税抜79〜128円）はありませんでした。そこで、代わりの商品もAIに提案してもらいました。カット野菜は玉ねぎサラダ、大根サラダ、にんじんミックスサラダにしています。

AIは献立と買い物リストを、商品の写真つきのページにまとめてくれました。リストの合計は税込で約13,000円（税抜で約12,000円）になり、送料無料の条件を満たしました。

我が家ならではの事情も伝えました。たとえば牛乳は、娘が「ギューギュー」と言いながらねだるので減りが早く、冷蔵庫には常に3本ほど置いておきたいと伝えました。

ちょっとだけランダム要素も追加

我が家では基本的に毎回私が買い物に行っているため、どうしても同じようなものばかり買ってしまうんですよね。

そこで、AIにちょっとだけランダムに商品を選んでもらうようにしました。土日の昼に食べる温めるだけのごはんもの（ビビンバ、炒飯、ピラフなど12品）から、毎週2袋をAIが選びます。

毎週の買い物をさらに効率化する

マイリストへの登録

ライフのネットスーパーには「マイリスト」という機能があります。商品ページのハートマーク（お気に入りのボタン）を押すと、その商品がマイリストの「お気に入り商品」に入り、次からはその一覧からカートに入れられます。

マイリストに商品を登録すれば、毎週の買い物はかなり楽になります。（AIエージェントにとっても楽になります）

マイリストに登録した商品の一覧のイメージ（生成AIで作成）

買い物量の調整

量を調整する必要があるものと言えば、ピルクルです。ピルクルとは要するにヤクルトみたいなもので、うちでは鉄分入りのピルクルを重宝しています。ピルクルは基本10個入りで、我が家では1日に2個消費します。つまり、1週間では14個必要です。1セットでは4個足りません。

一週間1セットで足りないからといって、毎週2セットずつ購入していると、毎週6個ずつ余っていきます。これを繰り返していると、どんどん在庫が増えてしまいます。

賞味期限による廃棄は考えていません。

そこで、AIに在庫を考慮して購入数量を調整してもらうことにしました。たとえば、注文するときに残りの数をAIに伝え、4個以上残っていれば1セット、4個未満なら2セット買います。

食パンも同じです。我が家では8枚切りを毎日4枚、1週間に3袋半くらい消費するので、4袋買う必要があります。ただ、これを毎週繰り返していると、だんだん余っていくんですよね。こういった商品についても、AIに購入数量を調整してもらいます。

日用品の購入も効率化する

日用品（トイレットペーパー、洗剤、ボディソープの詰め替えなど）についても、ライフのネットスーパーで購入できるものと、購入できないものがあります。レシートにあった日用品を調べると、クリニカの洗口液を除いて、同じか近い商品がライフにありました。レシートには出てこないものの家で使っている日用品も調べると、浄水器のカートリッジ、掃除機の紙パック、加湿器のフィルターはありませんでした。

そこで、購入できるものはライフのネットスーパーにまとめ、取り扱いのないものはAmazonの定期購入を利用することにしました。

「ない」側の写真は、生成AIで作ったイメージです。

ほかのネットスーパーやAIでもできる？

ここまでの話は、ライフのネットスーパーと Claude in Chrome の組み合わせです。ネットスーパーの操作で私が試したのはこの組み合わせだけなので、ここからは「できそう」という話になります。

買い物できそうな主なAIエージェント

おそらく過渡期的な情報になりそうですが。2026年11月時点での情報でさらっとまとめます。

私が使った Claude in Chrome は、Claude の有料プランで使えます。カートに入れるところまではAIに任せられますが、購入はできない仕様なので、注文の確定は自分で行います。

ほかにも、ネットスーパーのようにログインが必要なページを操作できるAIは、次のようなものがあるらしいです。アップデートで変わりやすいので、料金や対応地域は各サービスで確かめてください。

  • ChatGPT の拡張機能（Codex のアプリから使う形もあるようです）
  • Manus
  • Perplexity Comet（イオンネットスーパーのカートに商品を入れた例があるようです）
  • Meta の Muse
  • Playwright MCP（専用の拡張機能を入れると、いつものブラウザのタブにつなげるようです）
  • Chrome DevTools MCP（起動している Chrome につなげるようです）

さいごに

レシートの分析から、献立、買い物リスト、マイリストへの登録、毎週の数の調整まで、AIに任せることができます。店に行く時間だけでなく、何を買うか、いくつ買うかを毎回考える手間も減らせます。

今回はライフのネットスーパーの例でしたが、Claude in Chrome は画面を見ながら操作するので、パソコンのブラウザで注文できるネットスーパーなら、同じようにできると思います。お使いのネットスーパーで、試してみてください。
